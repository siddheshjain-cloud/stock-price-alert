    spa-run <TASK-ID>

1. map a task ID to the predefined implementation/review model,
2. select/use the correct provider/model/reasoning without asking the user to remember routing,

5. load the correct task/review prompt or governing plan reference,
6. invoke the task,
7. report the result clearly,
8. never silently proceed under the wrong model.
