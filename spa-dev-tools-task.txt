1. spa-check.ps1 — DIAGNOSTIC ONLY
============================================================

Purpose:
One command tells a non-developer whether the SPA development workspace is ready.

Defaults:
BackendPath = C:\GitHub\backendtest
FrontendPath = C:\GitHub\stock-price-alert
PythonPath = C:\venvs\spa-m1\Scripts\python.exe
ExpectedBranch = feature/investment-operating-system-m1

Allow these as optional parameters so tests can use temporary repos.

Checks:
- backend path exists and is a Git repo
- frontend path exists and is a Git repo
- current branch for each repo
- short HEAD for each repo
- working tree clean/dirty using git status --porcelain
- local upstream name and local ahead/behind if an upstream already exists
- DO NOT fetch or contact network
- fixed Python exists
- Python reports 3.12.x
- pytest is available via:
  <PythonPath> -m pytest --version

Output should be compact and readable, approximately:

FRONTEND  OK  feature/investment-operating-system-m1  c6eb7d20  CLEAN
PYTHON    OK  Python 3.12.10
PYTEST    OK  pytest x.y.z
READY     YES

READY is YES only when both repos exist, are Git repos, are on ExpectedBranch, are clean, Python is 3.12.x, and pytest works.

Exit 0 when READY YES; exit nonzero when READY NO.

STRICT SAFETY:

3. spa-deps-sync.ps1 — REUSE DEPENDENCIES
============================================================

Purpose:
Avoid reinstalling Python/packages on every task.

Defaults:
BackendPath = C:\GitHub\backendtest
PythonPath = C:\venvs\spa-m1\Scripts\python.exe

Optional switches:
-Force
-CheckOnly

Rules:
- Never download/install Python.
- Never create another venv.
- Never modify repo files.
- Require the fixed Python path to exist.
- Require requirements-dev.txt to exist.
- Fingerprint all requirements*.txt files in the backend root in deterministic filename order.
- Store only the resulting fingerprint marker under C:\venvs\spa-m1, not in Git.
- If fingerprint matches and -Force is not supplied: print DEPENDENCIES CURRENT and do nothing.
- If -CheckOnly and fingerprint differs/missing: print SYNC NEEDED and do not install.
- Otherwise run only:
  <PythonPath> -m pip install -r <BackendPath>\requirements-dev.txt
  <PythonPath> -m pip check
- Write/update the fingerprint marker only after both commands succeed.
- Fail closed on errors.

Do NOT upgrade pip automatically.
